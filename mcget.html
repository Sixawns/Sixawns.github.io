MCget

Minecraft 版本下载器 —— 只下载，不启动

它做什么

把某个版本的完整文件拉到本地，交给 PCL / HMCL 启动。 不碰账号、不破解、不绕过任何验证。

特性

零依赖核心

mcget.py 只用 Python 标准库

四个加载器

Forge / NeoForge / Fabric / Quilt

断点续传

已下好的自动跳过，断了重跑接着下

SHA1 校验

校验通过才写盘，损坏自动重下

多线程

实时速度、剩余时间、字节级百分比

图形界面

CustomTkinter，随时停止

命令行

python mcget.py list --mirror          # 看看有哪些版本
python mcget.py download 1.20.1 --mirror
python mcget.py download 1.20.1 --mirror --dir D:/Minecraft/.minecraft

python mcget.py fabric 1.20.1          # 版本留空 = 最新稳定版
python mcget.py quilt 1.20.1
python mcget.py forge 1.20.1 47.4.13
python mcget.py neoforge 1.21.1

命令行下也会显示实时进度：

[ 42%] 74.3 MB / 180.5 MB | 文件 512/1234 | 3.2 MB/s | 剩余 33 秒

界面能做的事

  • MC 版本 下拉框选，勾「显示测试版」会多出快照版本
  • 游戏目录 填你的 .minecraft，一般就是 PCL / HMCL 在用的那个
  • 国内加速镜像 国内开着快很多，人在国外可以关
  • 同时下载 同时下几个文件，16 左右比较稳
  • 加载器 Fabric / Quilt / Forge / NeoForge 四选一
  • 进度 百分比、已下/总量、实时速度、剩余时间
  • 停止 随时打断，下好的文件留着，再点一次接着下

版本都留空就自动选最新的，不用查版本号。 鼠标停在任意选项上，底部会显示它是干什么的。

打包成 exe

Windows 上双击 build_exe.bat，自动建虚拟环境、装依赖、打包：

dist\mcget.exe      图形界面，双击即用
dist\mcget-cli.exe  命令行版

别用裸命令 pyinstaller -F -w mcget_gui.py。 customtkinter 没有官方 hook，主题 json 和字体会漏掉，打出来的 exe 双击直接崩。走 spec 才对。

分层

mcget.py ──(两个回调)──> mcget_gui.py
 下载逻辑                  界面
 不认识界面                不碰下载细节

界面只通过两个 hook 订阅事件，两边互不依赖。 想换界面（Qt / 网页套壳），只需重写 mcget_gui.py，mcget.py 一行不动。
